> Tell my boss I quit. Effective immediately. Forever.

**52 characters** of the 150-character limit.

## Concept

The dead person treats their tombstone as the office notice board:
they resign from the grave. "Effective immediately" is the driest
corporate phrase there is; "Forever" turns it into a dying
declaration. One short line, no explanation needed, and easy to
repeat to a friend.

## How it works

`main.py` (Python standard library only, fully deterministic) holds
the line as a constant, validates it against every gate in the brief
— one line, 1 to 150 characters, no empty or whitespace-only text,
no leading or trailing whitespace, no control characters — then
prints it and writes it to `/output/entry.txt`.

Run it with:

```
python3 main.py
```
